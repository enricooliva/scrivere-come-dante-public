# Dati

Collocare il corpus in `data/commedia.txt` con codifica UTF-8.

Il programma costruisce automaticamente un vocabolario formato da tutti i caratteri distinti presenti nel file e divide la sequenza nel seguente modo:

- primo 90%: training;
- ultimo 10%: validation.

## Avvertenza editoriale

La *Divina Commedia* è un'opera di pubblico dominio, ma una specifica edizione digitale, la sua trascrizione, le note e l'apparato editoriale possono avere condizioni d'uso proprie. Il repository non include automaticamente alcuna edizione.
